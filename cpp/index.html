Thực hành C++

Tất cả bài tập chấm tự động của khóa ở một nơi. Chọn bài, viết code, chạy thử trên trình mô phỏng rồi nộp bài. Bí thì mở gợi ý; lời giải mở khi bạn đã làm đạt hoặc đã nộp 3 lần chưa đạt, kèm trình tự chạy từng bước.

Cách A · MSYS2 + g++ Khuyên dùng với VS Code

            
    
              
  1. Tải bộ cài từ msys2.org, cài vào thư mục mặc định C:\msys64.
    2. 
              
  2. Mở ứng dụng MSYS2 UCRT64 từ Start menu và cài bộ công cụ:
                
    pacman -S --needed base-devel mingw-w64-ucrt-x86_64-toolchain
    
                Nhấn Enter để chọn tất cả gói, rồi gõ Y để xác nhận.
    3. 
              
  3. Thêm thư mục chứa g++ vào PATH: tìm “Edit environment variables for your account” → chọn Path → New → dán:
                
    C:\msys64\ucrt64\bin
    4. 
              
  4. Đóng hết cửa sổ terminal, mở PowerShell mới và kiểm tra:
                
    g++ --version
    5. 
            

          

          

            
Cách B · Visual Studio Community

            
    
              
  1. Tải Visual Studio Community (miễn phí cho cá nhân và học tập) từ visualstudio.microsoft.com.
    2. 
              
  2. Trong Visual Studio Installer, chọn workload Desktop development with C++.
    3. 
              
  3. Tạo project Console App và bấm F5 để chạy. Cách này dùng trình biên dịch MSVC.
    4. 
            

          

        



          

            
Command Line Tools của Apple (Clang)

            
    
              
  1. Mở ứng dụng Terminal và cài công cụ dòng lệnh:
                
    xcode-select --install
    2. 
              
  2. Kiểm tra. Kết quả sẽ hiện “Apple clang version …”:
                
    clang++ --version
    3. 
              
  3. Lệnh g++ cũng dùng được, nhưng thực chất vẫn gọi Clang. Muốn dùng GCC thật thì cài qua Homebrew:
                
    brew install gcc
    
                Sau đó gọi bằng tên có số phiên bản, ví dụ g++-14.
    4. 
            

          

        



          

            
Ubuntu / Debian

            
    
              
  1. Cập nhật danh sách gói:
                
    sudo apt update
    2. 
              
  2. Cài g++, make và trình gỡ lỗidebugging gdb:
                
    sudo apt install build-essential gdb
    3. 
              
  3. Kiểm tra:
                
    g++ --version
    4. 
            

          

          

            
Fedora
