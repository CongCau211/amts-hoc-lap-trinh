HƯỚNG DẪN

      
Chạy code của bạn từ STM32CubeIDE

      
    
        
  1. Tạo project, chọn board NUCLEO-F103RB (hoặc chip STM32F103RBTx).
    2. 
        
  2. Viết code, bấm Build (Ctrl + B). Không cần bấm Run vì không có mạch nạp thật.
    3. 
        
  3. Bấm Nạp file .elf hoặc kéo thả file TênProject/Debug/TênProject.elf vào trang.
    4. 
        
  4. Muốn khỏi nạp tay: bấm Tự nạp khi Build (Chrome hoặc Edge trên máy tính), chọn file .elf một lần. Mỗi lần Build xong, trang tự nạp và chạy lại sau khoảng 1 giây.
    5. 
      

      
Board ảo

      
    
        
  • B1 (PC13): giữ chuột hoặc ngón tay để nhấn, thả ra để nhả. Board có điện trở kéo lên nên nhả = 1, nhấn = 0. Bàn phím: chọn nút rồi giữ phím cách.
    • 
        
  • LD2 (PA5) sáng khi chân ở mức 1, mờ dần theo độ rộng xung khi chân đảo nhanh. LD1 nháy khi có dữ liệu trên cổng COM.
    • 
        
  • Cổng COM là USART2 (PA2/PA3), giống cổng COM ảo của ST-LINK trên board thật; printf trong code mẫu in ra đây.
    • 
      

      
Bài tập

      
    
        
  1. Mẫu Nháy LED: đổi HAL_Delay(500) thành 100, Build lại, xem LED nháy nhanh hơn.
    2. 
        
  2. Mẫu Ngắt timer: tính lại Prescaler và Period để LED đảo mỗi 1 s. Kiểm bằng ô Thời gian chip ở phần CPU.
    3. 
        
  3. Mẫu UART: khi gõ chữ a thì bật LED, chữ t thì tắt.
    4. 
        
  4. Mẫu Lỗi quên clock: sửa cho LED sáng, xem tab Cảnh báo hết báo.
    5. 
      

      
Đã mô phỏng

      
    
        
  • CPU Cortex-M3: đủ tập lệnh Thumb-2 mà GCC sinh ra, NVIC, ưu tiên ngắt, SysTick, ngủ WFI, chạy được FreeRTOS.
    • 
        
  • Ngoại vi: RCC (HSI, PLL, bộ chia), FLASH latency, GPIO A–E, AFIO, EXTI, TIM1–TIM4 (đếm, ngắt, PWM), USART1–3, ADC1.
    • 
        
  • Bộ nhớ như chip thật: flash 128 KB tại 0x0800 0000, RAM 20 KB tại 0x2000 0000.
    • 
      

      
Mô hình và giới hạn

      
    
        
  • Mô hình là mức lệnh và thanh ghi, không mô phỏng điện: không có điện áp thật, dòng, nhiễu, dội phím. Mức logic chỉ là 0 hoặc 1; chân thả nổi đọc về 0.
    • 
        
  • Thời gian mỗi lệnh lấy gần đúng theo số chu kỳ của Cortex-M3 (sai lệch vài chục phần trăm, không mô phỏng wait state của flash). Thời gian của timer, SysTick, UART, ADC tính theo xung nhịp đã cấu hình nên HAL_Delay và ngắt timer đúng giờ; vòng chờ bằng for thì không chính xác.
    • 
        
  • ADC lý tưởng: giá trị = điện áp ÷ 3,3 V × 4095, làm tròn; không có sai số offset, nhiễu hay sai số lượng tử ngoài bước 1 LSB.
    • 
        
  • Chưa mô phỏng: I2C, SPI, DMA, CAN, USB, RTC, watchdog, input capture, encoder, ghi flash. Firmware dùng các phần này sẽ được báo ở mục Cảnh báo.
    • 
        
  • Code chạy đúng ở đây vẫn phải thử lại trên board thật. Đây là công cụ học, không phải công cụ kiểm định phần cứng.
